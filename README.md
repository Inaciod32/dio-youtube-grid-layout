# DevTube — Desafio CSS Grid DIO

Projeto desenvolvido como parte do desafio de CSS Grid da formação de CSS da DIO.

## Objetivo

Construir uma página de listagem de vídeos inspirada no YouTube, praticando principalmente:

- CSS Grid Layout
- Flexbox
- HTML semântico
- Responsividade
- Organização de componentes visuais
- Boas práticas básicas de acessibilidade

## Tecnologias

- HTML5
- CSS3

## Estrutura

```text
dio-youtube-grid/
├── index.html
├── style.css
├── README.md
└── assets/
    └── thumbnails em SVG
```

## Destaques do projeto

- Cabeçalho fixo
- Barra lateral de navegação
- Campo de busca
- Grid responsivo de vídeos
- Cards com capa, duração, título, canal e visualizações
- Identidade visual própria com conteúdo voltado a desenvolvimento Front-end
- Layout adaptado para desktop, tablet e celular
